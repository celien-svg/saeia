# FAQ et dépannage

??? question "Quels formats d'image puis-je utiliser ?"
    Les formats d'image courants, comme JPG et PNG, sont acceptés. Les images
    sont adaptées automatiquement avant leur enregistrement.

??? question "Pourquoi mon ordinateur ne peut-il pas être enregistré ?"
    Vérifiez les champs obligatoires : nom, localisation et entité. Vérifiez
    aussi que l'étiquette ULCO n'est pas déjà associée à un autre ordinateur.
    Voir [Ajouter un ordinateur](utilisation/ajouter-ordinateur.md).

??? question "Pourquoi aucune anomalie n'est-elle affichée ?"
    Vérifiez qu'une photo avant et une photo après existent pour la même zone.
    Vérifiez également que le service d'analyse est disponible. Si le problème
    persiste, demandez de l'aide à l'administrateur.

??? question "L'IA a-t-elle toujours raison ?"
    Non. Un reflet, une poussière ou un changement d'angle peut produire un
    faux positif. Comparez les photos vous-même et utilisez la validation
    humaine pour conserver la décision réellement retenue.

??? question "Comment conserver les photos existantes lors d'une modification ?"
    Laissez les champs photo vides dans le formulaire de modification. Seules
    les zones pour lesquelles vous fournissez une nouvelle photo sont
    remplacées.

??? question "Que faire si l'analyse ne fonctionne pas ?"
    Vérifiez que les photos avant et après sont bien présentes pour la même
    zone. Si le problème persiste, transmettez le message affiché à
    l'administrateur. Les photos et les rapports déjà enregistrés restent
    conservés.

## Besoin d'aide ?

Avant de signaler un problème, notez :

1. le nom de l'ordinateur ;
2. la zone analysée ;
3. l'action effectuée ;
4. le message affiché ;
5. l'heure approximative du problème.

Ces informations permettent à l'administrateur de comprendre rapidement le
problème.
